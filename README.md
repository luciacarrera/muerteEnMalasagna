# muerteEnMalasagna

Creates options for bingo cards. 

The program currently has the following categories:
- tiktoks 
- northern bars
- bars
- southern bars
- repeated actions
- easy search
- hard search

There are three bar categories, so every team has to cover about the same distance ont their trip. 
"bars" means bars in the center of Malasana. 
Each category has one bingo action except for repeated_actions and bars. Two "bars" are chosen. One action will include taking shots and one will be just normal drinks.
All repeated actions will be put in the bingo for all teams.
No team will go to the same bar.
